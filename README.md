# openai-codex-test

Testing out OpenAI Codex.

## Development environment

This project uses a local Python virtual environment located in `.venv/` and
stores application code inside the `src/` package. To get started:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
```

Add project dependencies with `pip install <package>` and freeze them into
`requirements.txt` as the project grows.
